 Closes pico: destroys the window and terminates the library. Releases every resource still alive: those loaded implicitly by path or content (pico_output_draw_image, pico_output_draw_text, pico_output_draw_video, pico_output_sound_path, pico_set_pencil_font_path), and those created explicitly and not yet freed (pico_layer_*, pico_font_load, pico_sound_load). void pico_close ( void )

Closes pico: destroys the window and terminates the library. Releases every resource still alive: those loaded implicitly by path or content (pico_output_draw_image, pico_output_draw_text, pico_output_draw_video, pico_output_sound_path, pico_set_pencil_font_path), and those created explicitly and not yet freed (pico_layer_*, pico_font_load, pico_sound_load). Every handle is invalid afterwards. The automatic exit on window close (see pico_set_aids) goes through this same call.
